Make embeddings.json

Developer tool, run once. The site compares each photo with text descriptions like "a photo of feet". This page turns those descriptions into numbers (embeddings) and saves them as embeddings.json, so visitors don't have to download the 43 MB text model.

Run it again whenever you change the prompts in scoring.js.

  1. Click the button and wait (downloads the text model once).
  2. Save the downloaded embeddings.json into the docs/ folder.
  3. Commit and push.
